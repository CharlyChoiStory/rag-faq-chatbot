# PlayMCP 카카오톡 연결 체크리스트

작성일: 2026-05-16

## 1. 확인 목적

PlayMCP가 다음 중 어디까지 가능한지 확인한다.

1. AI가 카카오톡 “나와의 채팅방”으로 메시지를 보내기
2. 외부 API(`/api/kakao-chat`) 호출 결과를 카카오톡으로 보내기
3. 카카오톡에서 사용자가 보낸 질문을 AI/외부 API로 전달하기

현재 PoC의 핵심 질문은 3번이다. 3번이 불가능하면 PlayMCP는 알림/전송용으로 쓰고, 양방향 챗봇은 카카오 채널 Webhook 방식으로 구현한다.

## 2. 찰리 확인 절차

1. `https://playmcp.kakao.com` 접속
2. 카카오 계정 로그인
3. 도구함에서 카카오톡 관련 도구 검색
4. 다음 도구가 있는지 확인
   - 나와의 채팅방 메시지 보내기
   - 카카오톡 메시지 조회 또는 수신 트리거
   - 외부 URL/API 호출 도구
   - MCP 도구 조합 또는 워크플로우 구성 기능
5. 연결 프롬프트 생성
6. Claude / ChatGPT / OpenClaw 중 하나에 연결 프롬프트 붙여넣기
7. 테스트 메시지 전송

## 3. 테스트 문장

### 3.1 단순 카톡 전송 테스트

```text
카카오톡 나와의 채팅방으로 “PlayMCP 연결 테스트입니다.”라고 보내줘.
```

성공 기준:

- 스마트폰 카카오톡 “나와의 채팅방”에 메시지가 도착한다.

### 3.2 RAG 답변 수동 전송 테스트

로컬 또는 배포된 API가 준비된 뒤 테스트한다.

```text
다음 API에 POST 요청을 보내서 answer 또는 kakaoText를 받은 뒤, kakaoText를 카카오톡 나와의 채팅방으로 보내줘.
URL: https://배포주소/api/kakao-chat
Body: {"question":"연차는 며칠 전까지 신청해야 해?","channel":"kakao"}
```

성공 기준:

- API 응답의 `kakaoText`가 카카오톡으로 전송된다.

### 3.3 양방향 가능성 확인 질문

```text
내가 카카오톡 나와의 채팅방에 새 메시지를 보내면, 그 메시지를 읽어서 이 AI에게 전달하고 다시 답변을 보내는 자동 응답 구성이 가능한지 확인해줘.
```

성공 기준:

- PlayMCP가 수신 트리거 또는 메시지 조회 기능을 제공한다고 확인된다.

실패 기준:

- PlayMCP가 메시지 보내기만 지원한다.
- 사용자가 카카오톡에 보낸 메시지를 자동으로 AI에게 전달할 방법이 없다.

## 4. 헤르미/챗팀장 확인 항목

- `/api/kakao-chat`가 일반 JSON 응답을 정상 반환하는가?
- `userRequest.utterance` 입력 시 Kakao OpenBuilder `simpleText` 응답을 반환하는가?
- 답변 길이가 카카오톡에서 읽기 적절한가?
- 출처가 너무 길지 않은가?
- 오류 발생 시 사용자에게 안전한 문구가 나가는가?

## 5. 판단 기준

### PlayMCP만으로 진행 가능

조건:

- 외부 API 호출 가능
- API 결과를 카카오톡으로 전송 가능
- 사용자가 어느 정도 수동으로 AI에게 질문하는 흐름이어도 PoC 목적에 맞음

용도:

- 빠른 시연
- 나와의 채팅방 알림
- 헤르미/챗팀장이 요약한 결과를 카톡으로 보내기

### 카카오 채널/Webhook 필요

조건:

- 스마트폰 카카오톡 안에서 사용자가 직접 질문해야 함
- 일반 직원들이 카톡 채널을 통해 반복 사용해야 함
- PlayMCP가 카톡 메시지 수신/자동응답을 지원하지 않음

용도:

- 실제 사내 챗봇 PoC
- 외부 사용자 테스트
- 카카오톡 UX 중심 시연

## 6. 보안 주의

- `.env.local` 값, OpenAI API Key, Supabase Service Role Key, Notion API Key는 PlayMCP/AI 채팅창에 붙여넣지 않는다.
- 배포 URL은 HTTPS를 사용한다.
- 카카오 Webhook으로 확장할 경우 인증 토큰 또는 서명 검증을 추가한다.
- 사내 규정 데이터가 외부 카카오/AI 서비스로 전달되는 범위를 찰리가 승인한 뒤 테스트한다.
